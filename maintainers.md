## Maintainer Responsibilities

The project maintainer is responsible for:

* Reviewing and merging contributions.
* Triaging bug reports, feature requests, and questions.
* Maintaining compatibility with supported Python versions and dependencies.
* Reviewing changes for correctness, reliability, and security.
* Maintaining project documentation and usage examples.
* Preparing releases and maintaining release notes.
* Addressing reported security vulnerabilities in accordance with [SECURITY.md](SECURITY.md).

## Contributions and Code Review

Contributions from the community are welcome.

Contributors should submit changes through pull requests against the project's repository. Pull requests may be reviewed for:

* Correctness and consistency with existing project behavior.
* Compatibility with supported platforms and Python versions.
* Test coverage and reproducibility.
* Documentation updates where applicable.
* Potential security, performance, and reliability concerns.

The maintainer may request changes, defer a contribution, or decline a pull request when appropriate.

Submitting a pull request does not guarantee that it will be accepted or merged.

## Issues and Feature Requests

Bug reports and feature requests should be submitted through the repository's GitHub issue tracker.

Reports should include relevant information, such as:

* The affected SARP version.
* The operating system and Python version, where applicable.
* Steps to reproduce the issue.
* Relevant error messages, logs, or sample inputs.

Security vulnerabilities should be reported according to [SECURITY.md](SECURITY.md) rather than through public issues.

## Releases

The project maintainer is responsible for preparing and publishing official releases.

Release notes should document relevant changes, including new features, bug fixes, compatibility changes, and known issues where applicable.

Official release artifacts should be distributed through the project's GitHub Releases page.

## Changes to Maintainers

Changes to project maintainership, including the addition of new maintainers or the transfer of maintenance responsibilities, should be documented by updating this file.
