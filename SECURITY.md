# Security Policy

## Scope

Security vulnerabilities in the parser, its input processing, configuration handling, and generated output are in scope. Security fixes target the latest release and main. Older releases are not maintained.

Issues in third-party tools or dependencies should generally be reported to their respective maintainers unless SARP's use of the dependency creates the vulnerability.

## Reporting a Vulnerability

If you discover a security vulnerability in the Static-Analysis-Results-Parser, please report it responsibly:

1. Do not open a public issue.
2. Use GitHub's private vulnerability reporting to submit your report directly.
3. Include a description of the vulnerability, steps to reproduce, and any relevant logs or screenshots.

To report a security issue, please use the GitHub Security Advisory "Report a Vulnerability" tab.

The team is very responsive to reported vulnerabilities - historically having reported issues resolved in 30 days or less.

Thank you for helping improve the security of Static Analysis Results Parser.
